# B站弹幕自动化

一个发送弹幕工具：监控选定主播的直播间，开播后按设定的间隔自动发送弹幕，下播后自动停止。当然也可以在主播未开播状态下发送弹幕（有什么意义呢🤔）
程序可在后台运行，不需要打开网页也能发送弹幕。

> **使用前请先读[免责声明](#免责声明)。** 本程序是个人开发的第三方工具，和哔哩哔哩官方没有任何关系。
> 自动发送弹幕可能违反B站的用户协议和社区规范，账号可能被限流、禁言甚至封禁，风险由使用者自己承担。
> 请只在主播同意的直播间或你自己的直播间使用，千万不要用来刷屏或骚扰他人。

## 这个工具有什么用

- 可同时监控多个直播间，开播时自动开始发送弹幕、下播自动停止
- 勾选监控（或打开程序）时主播已经在播的那一场只监控、不发送，点“本场开始发送”才开始发；之后每次开播照常自动发送
- 包含三种模式：始终发送同一句弹幕（可以和表情轮流发，包括账号买过的装扮表情）；把一段长文字按顺序切成多条依次发送；只提醒开播、不发弹幕
- 固定间隔或随机间隔，最短1秒；建议最小间隔为5秒，短于5秒时可能会被B站拦截
- 发送限制：每场最多发多少条、多少分钟，或者只在每天某个时段发送
- 弹幕收藏夹：可将文字保存在程序内以便快速找到想要发送的内容
- 历史记录：每次发了多久、成功和失败各多少条、每条失败的原因；按直播间、按天统计
- 开播、下播、停止发送时弹系统通知
- 可以开机自动启动
- 数据一键导出备份，换电脑时一键恢复

只支持 Windows 10（1809及以上）和 Windows 11 的64位系统。

## 下载和安装

1. 到 [Releases](https://github.com/Adaaachiii/bili-auto-danmaku/releases) 下载最新的 `BiliAutoDanmaku-v版本号-win-x64.zip`。
2. 解压到一个你有写入权限的文件夹，比如 `D:\软件`。
   放在 `C:\Program Files` 也能用，但数据会改存到 `%LOCALAPPDATA%\BiliAutoDanmaku`，而且没法用“从压缩包更新”（见[数据保存在哪](#数据保存在哪)）。
3. 双击里面的 **B站弹幕自动化.exe**。

第一次运行时 Windows 可能提示“Windows 已保护你的电脑”：exe 没有数字签名，点“更多信息 → 仍要运行”。

## 快速上手

1. 第一次打开会弹出“使用须知”，看完点“我知道了”。
2. 点左下角的 **未登录 / 点击登录**：用B站 App 扫码，或者粘贴 Cookie。登录后左下角显示头像和昵称，点它可以切换账号或退出登录。
3. 在 **直播间** 页点 **＋ 添加直播间**：填房间号或直播间链接 → 点“查询”确认主播 → 选模式、填内容和间隔 → 保存。
4. 不用再管它。点 × 时可以选最小化到托盘（继续运行）还是退出；想开机自动运行，到左侧 **设置** 里勾选。

左侧功能栏：**直播间**、**弹幕收藏夹**、**历史记录**，左下方为 **设置** 和账号。

## 升级到新版本

在 Releases 下载新版本的压缩包（不用解压），打开程序 → **设置** → 最下面版本号旁边的 **从压缩包更新…** → 选中刚下载的压缩包 → 确认。
程序会自己解压、替换文件并重新打开，直播间、收藏夹、历史记录等数据都不受影响。替换过程中出错会自动恢复成旧版本。

- 程序文件夹不能写入（比如放在 `C:\Program Files`）时没法自动更新。可以先退出程序，把整个程序文件夹挪到 D 盘等位置再更新，或者手动覆盖（见下一条）。

## 卸载

1. 先到 **设置** 里取消“开机自动启动”，保存。
2. 点左下角的账号 → 退出登录，选“退出并注销”（或“只删除本机保存的”），Windows 凭据管理器里保存的 Cookie 会被删掉。
3. 托盘图标右键 → 退出。
4. 删掉程序文件夹。如果数据存在 `%LOCALAPPDATA%\BiliAutoDanmaku`，把它也删掉。

## 三种模式（每个直播间可单独选择）

**独轮车模式**：按间隔一直发同一句弹幕（也可以和表情轮流发），一句最多40字。

- **表情**：点“选择表情…”挑几个表情，和文字轮流发（文字→表情1→表情2→……→文字），下面那一排拖动可以调整顺序；不填文字就只发表情。
  能选的是这个账号在这个直播间能用的表情：通用表情、房间专属表情，以及买过的装扮表情（收藏集）。要先登录、先查询直播间；还没解锁的表情是灰色的，鼠标停在上面能看到解锁条件。
- **随机顺序**（可选）：每次随机挑一条发，但不会连着发同一条。
- 每场直播都从文字（没填文字就从第一个表情）开始轮。换了登录账号的话，新账号没有的表情会发不出去，到编辑里重新选一下。

**说书人模式**：把一段长文字按顺序切成多条弹幕，一条接一条地发，直到全部说完。

- 说书内容可以从收藏夹选，也可以直接粘贴或导入 txt（UTF-8、GBK 编码都行），不限字数。
- **每条字数**：默认40字（最多40），可以调小。
- **换行处理**：
  - 忽略换行：一行说完接着说下一行，原来换行的地方用空格隔开，每条都塞满字数（空格也算字数）；
  - 按行说书：一行说完就换下一条，不会把下一行的内容拼进同一条。
- 每行开头结尾的空白（包括全角缩进）和空行会自动去掉，不浪费字数。
- **说完以后**：停止发送，或者从头循环。
- **说书状态继承**：一场直播结束后停止，下一场从停下的地方接着说；不勾的话每场直播都从头说。进度会保存，程序重启也不丢。
- **预计**：编辑时显示“共多少条，每几秒一条，约多久后结束”；已经说了一部分的话，再显示“目前剩余多少条，约多久后结束”。随机间隔按平均值算，不算被限流、被屏蔽和不在发送时段的时间（鼠标停在旁边的问号上能看到）。
- 若某一段被B站过滤（比如含屏蔽词）会跳过继续往下说；被限流或网络出错时重发同一段。
- **跳过以前被屏蔽过的段落**（可选，默认不勾）：说到以前被系统屏蔽过（任何直播间）、或在这个直播间被主播屏蔽过的段落时直接跳过，不再发送，循环说书时不会每一轮都被拦一次。
  B站偶尔会误拦正常弹幕，勾上后这些段落以后也不会再发。被屏蔽过的段落记在屏蔽词整理表里（见“历史记录”）。
- 如果想从头开始发送：右键直播间 →“说书从头开始”，或者在编辑里点“重置（从头开始说书）”。

请注意：请只发送你有权发送的文字。未经授权把受版权保护的作品（比如小说）大段发到公屏上，可能侵犯他人的著作权。

**只提醒**：不发弹幕。开播、下播时弹系统通知，开播时可以自动打开直播页。
这种直播间的提醒不受设置里“系统通知”开关的影响，总会弹出来。

## 发送间隔

- 固定间隔：最短1秒。建议最小间隔为5秒，短于5秒时可能会被B站拦截导致发送失败，编辑直播间时的提示会变成黄色。
- **随机间隔**：勾上后填一个范围（比如10～30秒），每条弹幕在这个范围里随机选一个间隔。

## 发送限制（每个直播间单独设，默认都不限）

- **每场最多发多少条**：按发送成功的条数算，被屏蔽、被限流的不算。
- **每场最多发多少分钟**：从这一场发出第一条算起。
- **只在每天某个时段发送**：比如20:00到23:00。出了时段先不发，回到时段里接着发；结束时间早于开始时间表示跨过半夜，比如22:00到02:00。

到了条数或时长上限，这一场就停止发送，列表里显示“已达本场上限”，下一场（下次开播）重新计算。想在这一场里接着发，点“本场开始发送”。
历史记录里，到了上限的一场写“达到本场上限”；出了发送时段，那条记录在时段结束时结束，回到时段里发第一条时另起一条。

## 弹幕收藏夹

- 每条收藏有自己的**标题**，可以贴多个**标签**。标签显示成卡片，点卡片上的 × 去掉。
- 在标签框里输入新标签，按回车（或打逗号、空格）就变成卡片；保存后它会进入**常用标签**，下次新建收藏时点一下就能加上。常用标签上右键可以把它删掉（已经贴在收藏上的不受影响）。
- 字数显示准确字数（不算换行符）。
- 顶部搜索框同时检索标题、内容和标签；旁边可以按标签筛选。
- 收藏不限字数，可以直接导入 txt。长篇收藏在预览里只显示开头5000字，不影响速度。
- 编辑直播间时点“从收藏夹选择”就能用收藏里的内容。独轮车模式只能选40字以内的收藏。

## 历史记录

每个直播间每次“开始发弹幕 → 停止发弹幕”记一条，**发送不到5分钟的不保存**。

- 记录开始和结束时间、一共发了多久、发送 / 成功 / 失败各多少条，以及停下的原因：下播、手动停止、说书说完、连续失败自动停发、被禁言、暂停监控、登录失效、取消监控或删除直播间、程序退出等。
- 选中一条记录，下面会列出那次**所有失败的弹幕**和失败原因（系统屏蔽、主播屏蔽、被限流、被禁言、发送出错等，见下面的“发送失败的原因”），右键可以复制。
- 顶部可以按直播间和时间（今天、最近7天、最近30天、本月，或者自定义日期）筛选，按记录的开始时间算；可以多选删除不要的记录。
- 程序意外关闭（崩溃、断电）时还在发送的记录，下次打开程序会按最后一次发送的时间补上结束，原因写“程序异常退出”。

**统计**（历史记录页的第二个标签）：按上面选的直播间和时间范围，合计场数、总时长、发送 / 成功 / 失败条数和成功率，
并分别按直播间、按天（按一场开始的那天算）列出来；旁边是失败原因的分布（系统屏蔽、主播屏蔽、被限流等各多少条）。
只统计保存下来的记录（发送5分钟以上的）。

**屏蔽词整理表**：所有被B站过滤的弹幕（不管那次发了多久）都会汇总进数据文件夹里的 `被过滤的弹幕.csv`，
同一个直播间里同样的内容合并成一行，记被过滤了几次、屏蔽类型（系统屏蔽 / 主播屏蔽）、第一次和最近一次的时间。
用 Excel 可以直接打开、排序、筛选。在历史记录页点 **打开屏蔽词整理表** 就能打开。
被限流、网络出错这类和内容无关的失败不收进整理表（历史记录里照样能看到）。

## 每个直播间的其他选项

- **开播时自动打开直播页**
- **未开播时也发送弹幕**：勾上后不管开没开播都按间隔发送。勾上的时候、或打开程序时正好未开播，这一段要点“本场开始发送”才开始；下播后会自动接着发。
- **启用直播间状态监控**：取消勾选就暂时不管这个直播间，列表里显示“未监控”。

列表上方：

- **启用**（第一列）：勾上就开始监控这个直播间。勾上时主播已经在播的话，这一场只监控、不发送，列表里显示“等待手动开始发送”，点“本场开始发送”才发；之后每次开播照常自动发送。
- **全选**：一键监控或取消监控全部直播间；搜索时只作用于搜到的直播间。
- **搜索框**：按主播、房间号、弹幕内容或说书标题筛选。
- **多选**：按住 Ctrl 或 Shift 点选多个直播间，可以一起删除、打开、开始或停止发送、说书从头开始（编辑一次只能编辑一个）。
- **本场停止发送**：当前这一段先不发（这场直播，或这次未开播期间），开播或下播后照常自动处理。
- **本场开始发送**：手动开始发。勾选监控或打开程序时主播已经在播、刚把“只提醒”改成发弹幕、或者未开播时也发送的那一段，都要点它才开始。
- **暂停监控 / 继续监控**：暂停后不检测开播，也不发送弹幕。
- **立即检测**：不等倒计时，马上查一次所有直播间的开播状态。

下面的**运行日志**可以只看警告和错误、只看错误，也可以按关键词搜索；最多保留最近2000条。

## 设置项说明

| 设置 | 说明 |
|---|---|
| 检测间隔 | 多久查一次开播状态，默认30秒，建议大于30秒 |
| 程序启动后自动检测直播间状态 | 默认打开。关闭后，程序启动时先处于“暂停监控”，点“继续监控”才开始检测和发送 |
| 打开直播页用 | Edge、Chrome 或系统默认浏览器（选的浏览器没装时用系统默认浏览器） |
| 关闭窗口时 | 每次询问 / 最小化到托盘 / 退出程序 |
| 系统通知 | 开播、下播、说书说完、达到本场发送上限时，以及发送停下来时（被禁言、连续5次发送失败、登录失效）右下角弹通知。偶尔失败一两条只写进运行日志。“只提醒”的直播间不受这个开关影响 |
| 开机自动启动 | 写入当前用户的开机启动项，启动后直接缩到托盘 |

设置页最下面还有数据文件夹的位置、“导出备份…”“从备份恢复…”、版本号、“从压缩包更新…”和“使用须知”。

## 数据保存在哪

**数据文件夹**一般是程序文件夹（exe 所在的文件夹）下的 `data`。下面两种情况会改用 `%LOCALAPPDATA%\BiliAutoDanmaku`：

- 程序文件夹不能写入，比如放在 `C:\Program Files`。如果程序文件夹里已经有 `data`，第一次会把它复制过去。
- 程序文件夹里没有 `data`，但 `%LOCALAPPDATA%\BiliAutoDanmaku` 里已经有数据，比如以前放在 `C:\Program Files` 用过，后来挪了位置。

实际位置显示在设置页最下面，旁边有“打开文件夹”按钮。

| 内容 | 位置 |
|---|---|
| 登录 Cookie | Windows 凭据管理器（按你的系统账户加密，名字带 BiliAutoDanmaku） |
| 直播间和设置 | 数据文件夹里的 `config.json`（不含任何登录信息，也不含说书长文字） |
| 弹幕收藏夹 | `favorites.db` |
| 各直播间的说书文字 | `stories\房间号.txt` |
| 说书进度 | `progress.json` |
| 历史记录 | `history.db` |
| 屏蔽词整理表 | `被过滤的弹幕.csv`（带 BOM 的 UTF-8，Excel 打开不乱码） |
| 运行日志 | `logs\app.log`（不记录 Cookie）。每行带日期和时区，例如 `2026-10-17 01:00:54 UTC+8`，时区跟随 Windows 设置。满1 MB 换一个新文件，最多留4个，总共不超过4 MB |
| 更新记录 | `logs\update.log`（从压缩包更新时写） |
| 恢复前的数据 | `恢复前的数据-时间.zip`（从备份恢复时自动另存，确认没问题后可以删掉） |
| 表情图片 | `cache\emoticons`（选表情时下载的图片，删掉也没关系，用到时重新下载） |
| 开机自启（勾选时） | 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 里名为 BiliAutoDanmaku 的一项 |

除了表情图片，程序不产生其他缓存文件：头像每次启动重新下载，只放在内存里；exe 版也不会往临时文件夹解压东西。

### 备份和换电脑

设置页最下面点 **导出备份…**，把直播间和设置、收藏夹、历史记录、说书文字和进度、屏蔽词整理表打成一个 zip（不含登录、运行日志和表情图片）。
在新电脑上装好程序，点 **从备份恢复…** 选这个 zip：程序会关闭并自动重新打开，打开时换上备份里的数据。
换之前会把现在的数据另存成数据文件夹里的 `恢复前的数据-时间.zip`，换的过程中出错会保持原样。登录需要重新扫码。

### 隐私和安全

登录 Cookie 只发给 `*.bilibili.com`（Cookie 限定了域名，带登录的请求也不会跟着跳转到别的网站）；头像和表情图片从B站图片服务器 `*.hdslb.com` 下载（不带 Cookie）。
直播标题、主播昵称、表情名字这些别人能改的文字一律按纯文字显示，不会被当成网页内容去加载图片或文件。
退出登录时可以选“退出并注销”，让这份 Cookie 在B站服务器上也失效。

## 兼容性和资源占用

- **系统**：Windows 10（1809及以上）和 Windows 11，64位。不支持 Windows 7/8 和32位系统（界面库 Qt 6 的要求），也不支持 macOS 和 Linux。
- **硬盘**：exe 版解压后约80 MB（压缩包约33 MB）。数据很小，主要是收藏和说书文字本身，一百万字约3 MB。
- **内存**：约90～130 MB（刚启动约110 MB；带着43万字的说书文字约125 MB）。
  模拟连发6万条弹幕（相当于3个直播间每5秒一条、连续28小时），内存稳定在95 MB 左右，不会越用越多：运行日志窗口只保留最近2000行，日志文件也有上限。
- **长文字**：实测一百万字，整理文字8毫秒，切完全部约2.8万条弹幕13毫秒，在收藏夹里搜索7毫秒，打开编辑框14毫秒。
- **CPU 和网络**：大部分时间在等待。每个检测间隔查一次开播状态（所有直播间合成一次请求），每发一条弹幕一次请求。
- **显示**：跟随 Windows 的深色 / 浅色模式，高分屏下清晰。

## 发送失败的原因

B站没有公开发送弹幕接口的文档，下面的返回码来自社区整理（bilibili-API-collect）和开源项目，程序按这张表识别：

| B站返回 | 历史记录里写作 | 程序怎么处理 |
|---|---|---|
| code 0，msg `f` | 系统屏蔽：含B站全站的屏蔽词，弹幕只有自己看得到 | 收进屏蔽词整理表；说书模式跳过这段 |
| code 0，msg `k` | 主播屏蔽：含这个主播自己设置的屏蔽词 | 同上 |
| code 10031，或提示“频率过快”“msg in 1s”“msg repeat” | 被限流：发太快，或短时间重复同一句 | 下一条间隔加倍，同一段重发 |
| code -101、-111 | 登录失效：Cookie 失效或 csrf 校验失败 | 停止全部发送，提示重新登录 |
| code 1003212 | 发送出错：弹幕超出长度限制 | 需要把每条字数调小 |
| 提示里有“禁言”“拉黑” | 被禁言 | 这个直播间本场停止发送 |
| 其他返回码、网络超时、断网 | 发送出错 | 下一条重发 |

被限流、发送出错等失败连续5次，这个直播间本场就停止发送。**系统屏蔽和主播屏蔽不算**：它们不会让本场停发，也不会把前面累计的失败次数清零（比如出错3次、被屏蔽1次、再出错2次，照样停）。成功发出一条，失败次数清零。

## 需要知道的限制

- **弹幕长度**：一条最多40个字。
- **频率**：发得太快会被限流；同一句话短时间内重复发，可能被拦下或被房管禁言。建议发送间隔不短于5秒。
- **连续失败**：连续5次发送失败（被屏蔽不算），当前这一段会自动停发，避免一直报错。
- **接口**：用的是B站网页版自己的接口，没有公开文档，B站一改就可能失效，要等程序跟着更新。
- **账号风险**：自动发送弹幕可能违反B站社区规范，账号可能被限流、禁言或封禁，请自己评估。

## 常见问题

**提示“Windows 已保护你的电脑”，或者杀毒软件报毒**
exe 没有数字签名，第一次运行时 SmartScreen 会拦一下，点“更多信息 → 仍要运行”。
少数杀毒软件会误报 PyInstaller 打包的程序。不放心的话可以看仓库里的源码。

**打开后找不到窗口**
程序可能缩在托盘里。Windows 11 默认会把新的托盘图标收起来，点任务栏右下角的 `^` 展开，也可以把图标拖到任务栏上常驻。
再双击一次 exe 也会把已经打开的窗口叫出来（同一时间只会运行一个）。

**扫码登录没反应**
二维码约3分钟后过期，点“刷新二维码”重新扫。扫码一直不成功的话，可以改用“粘贴 Cookie”，登录框里有步骤说明。

**弹幕显示发出去了，但直播间里别人看不到**
多半是被B站的屏蔽词拦了：B站返回“成功”，但这条弹幕只有自己看得到。到历史记录里看失败原因，写着“系统屏蔽”或“主播屏蔽”的就是这种情况。

**程序打不开**
会弹窗提示，错误信息保存在程序文件夹下的 `启动错误.txt`（程序文件夹不能写入时在 `%LOCALAPPDATA%\BiliAutoDanmaku`）。
